## 验证步骤

1. 在 CMS 中修改当前测试标记。
2. 保存修改。
3. 检查 GitHub 中对应文档的内容和提交记录。
4. 检查 GitHub Actions 是否产生新的执行记录。
5. 如果工作流包含站点发布，检查发布后的页面是否显示新标记。

> 验证依据：保存后的文件、GitHub 提交记录和工作流执行结果应对应同一次修改。
